SPECIFICATION: [fx-dev Agent Authority](docs/specs/fx-dev-authority/index.md)
  SECTION: [Dev Runs Require User Approval Before Merge](#dev-runs-require-user-approval-before-merge)
    TEXT[!MUST,implication]: A `fx-dev:dev` run MUST obtain explicit approval from the user before merging any pull request it produced.

  SECTION: [Team Runs May Merge Within Approved Scope](#team-runs-may-merge-within-approved-scope)
    TEXT[!MAY,implication]: A `fx-dev:team` run MAY merge a pull request it produced without seeking further user approval, provided that pull request's work falls within the scope the user already approved.

  SECTION: [Required Checks Gate Every Merge](#required-checks-gate-every-merge)
    TEXT[!MUST,implication]: A pull request MUST NOT be merged while any required check on it is failing or has not completed.

  SECTION: [Unresolved Reviewer Threads Gate Every Merge](#unresolved-reviewer-threads-gate-every-merge)
    TEXT[!MUST,implication]: A pull request MUST NOT be merged while any review thread on it from a configured automated reviewer remains unresolved.

  SECTION: [Merge Gates Apply Regardless of Change Size](#merge-gates-apply-regardless-of-change-size)
    TEXT[!MUST,implication]: The size, triviality, or follow-up status of a pull request MUST NOT be treated as grounds for waiving any merge gate.

  SECTION: [The Dev Coordinator Delegates Implementation Writes](#the-dev-coordinator-delegates-implementation-writes)
    TEXT[!MUST,implication]: During an explicitly invoked `fx-dev:dev` lifecycle, the coordinator MUST delegate repository implementation edits and commits to sub-agents; it MAY perform mechanical coordination and GitHub operations directly.

  SECTION: [The Team Coordinator Delegates All Implementation](#the-team-coordinator-delegates-all-implementation)
    TEXT[!MUST,implication]: The `fx-dev:team` coordinator MUST NOT implement a task's code itself and MUST route all implementation work through agents it spawns.

  SECTION: [Spec Writer Touches Only the Docs Tree](#spec-writer-touches-only-the-docs-tree)
    TEXT[!MUST,implication]: The `fx-dev:spec-writer` skill MUST NOT create or modify any file outside the `docs/` tree.

SPECIFICATION: [Marketplace Structure](docs/specs/marketplace-structure/index.md)
  SECTION: [Marketplace Manifest Is Parseable](#marketplace-manifest-is-parseable)
    TEXT[!MUST,implication]: The repository MUST contain a `.claude-plugin/marketplace.json` file that parses as valid JSON.

  SECTION: [Marketplace Manifest Declares Its Identity](#marketplace-manifest-declares-its-identity)
    TEXT[!MUST,implication]: `.claude-plugin/marketplace.json` MUST declare the top-level fields `name`, `owner`, and `plugins`.

  SECTION: [Every Plugin Directory Carries a Manifest](#every-plugin-directory-carries-a-manifest)
    TEXT[!MUST,implication]: Every directory directly under `plugins/` MUST contain a `.claude-plugin/plugin.json` file.

  SECTION: [Plugin Manifests Are Parseable](#plugin-manifests-are-parseable)
    TEXT[!MUST,implication]: Every `plugins/*/.claude-plugin/plugin.json` file MUST parse as valid JSON.

  SECTION: [Plugin Manifests Declare Name and Version](#plugin-manifests-declare-name-and-version)
    TEXT[!MUST,implication]: Every `plugins/*/.claude-plugin/plugin.json` file MUST declare the top-level fields `name` and `version`.

  SECTION: [Declared Component Paths Resolve](#declared-component-paths-resolve)
    TEXT[!MUST,implication]: Every path listed in a plugin manifest's `skills` or `agents` array MUST resolve to an existing file, interpreted relative to that plugin's own directory.

  SECTION: [Marketplace Entries Resolve to Plugin Directories](#marketplace-entries-resolve-to-plugin-directories)
    TEXT[!MUST,implication]: Every entry in `.claude-plugin/marketplace.json` whose `source` begins with `./` MUST resolve to an existing directory that contains a `.claude-plugin/plugin.json` file.

  SECTION: [Plugin Markdown Carries Frontmatter](#plugin-markdown-carries-frontmatter)
    TEXT[!SHOULD,implication]: Every markdown file under `plugins/` other than a file named `README.md` SHOULD begin with a `---` frontmatter delimiter on its first line.
